# Getting help

- **Questions, ideas, "how do I…":** [Discussions](https://github.com/Delivery-Plus0/delivery-plus/discussions).
- **A bug:** open an issue in the repository it belongs to: the [backend](https://github.com/Delivery-Plus0/delivery-plus/issues), or the [customer](https://github.com/Delivery-Plus0/delivery-plus-customer-app/issues), [driver](https://github.com/Delivery-Plus0/delivery-plus-driver-app/issues) or [restaurant](https://github.com/Delivery-Plus0/delivery-plus-restaurant-app/issues) app. Not sure which one? Use the backend.
- **A security problem:** privately, as in [SECURITY.md](SECURITY.md). Never in a public issue.
